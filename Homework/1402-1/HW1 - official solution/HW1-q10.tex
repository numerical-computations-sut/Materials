فرض کنید می‌خواهیم تابع 
$f(x)$
را با استفاده از سری مک‌لورن توابع $\sin(x)$، $\cos(x)$ و $\tan^{-1}(x)$ روی بازه‌ی $[\frac{\pi}{2}, \frac{5\pi}{6}]$ حساب کنیم.
محاسبه کنید که هر کدام از این سه سری را حداقل باید تا چه مرتبه‌ای بسط دهیم تا خطایِ کلِ محاسبه‌یِ مقدارِ تابع روی کل بازه، از $10^{-5}$ کمتر شود.

$$f(x) = \frac{ 4\sin^2(x) - \cos(x) }{3\tan^{-1}(\frac{2x}{\pi \sqrt{3}})}$$

\end{comment}
پاسخ:

ابتدا تابع k را به صورت زیر تعریف می‌کنیم:
$$k(a,b,c) = \frac{4a^2 - b}{3c}$$
حال مشاهده می‌کنیم که 
$$f(x) = k(\sin(x), \cos(x), \tan^{-1}(\frac{2x}{\pi \sqrt{3}}))$$
برای راهنمایی در تخصیص بودجه‌ی خطا، از تقریب مرتبه‌ی اول زیر استفاده می‌کنیم:
$$d k = \frac{\partial k}{\partial a} d a + \frac{\partial k}{\partial b} d b + \frac{\partial k}{\partial c} d c$$

$$\frac{\partial k}{\partial a} = \frac{8a}{3c}$$
$$\frac{\partial k}{\partial b} = \frac{-1}{3c}$$
$$\frac{\partial k}{\partial c} = -\frac{4a^2-b}{3c^2}$$

حال حد بالایی برای مقادیر بیشینه‌ی این ضریب خطاها را روی بازه‌ی داده شده می‌یابیم:
برای سادگی بیشینه‌ی سینوس و کسینوس را ۱ در نظر می‌گیریم. همچنین دقت می‌کنیم که تابع وارون تانژانت صعودی است پس مقدار کمینه آن روی بازه، در نقطه $x=\pi/2$ اتفاق می‌افتد.

$$\abs{\frac{\partial k}{\partial a}} \leq \frac{8}{3 (\frac{\pi}{6})}$$
$$\abs{\frac{\partial k}{\partial b}} \leq \frac{1}{3 (\frac{\pi}{6})}$$
$$\abs{\frac{\partial k}{\partial c}} \leq \frac{5}{3 (\frac{\pi}{6})^2}$$

حال داریم:

$$|\Delta k| \leq \abs{\frac{\partial k}{\partial a} \Delta a} + \abs{\frac{\partial k}{\partial b} \Delta b} + \abs{\frac{\partial k}{\partial c} \Delta c}$$

$$|\Delta k| \leq \abs{ \frac{8}{3 (\frac{\pi}{6})} \Delta a} + \abs{\frac{1}{3 (\frac{\pi}{6})} \Delta b} + \abs{\frac{5}{3 (\frac{\pi}{6})^2} \Delta c}$$

حال داریم:

$$\frac{8}{3 (\frac{\pi}{6})} \approx 5.092$$
$$\frac{1}{3 (\frac{\pi}{6})} \approx 0.636$$
$$\frac{5}{3 (\frac{\pi}{6})^2} \approx 6.079$$

و می‌بینیم که 

$$10^{-2} \times 5.092 + 10^{-1} \times 0.636 + 10^{-1} \times 6.079 \approx 1$$

این محاسبه فقط یک راهنمای مرتبه‌ی اول برای تقسیم بودجه‌ی خطاست؛ بنابراین از صورت سؤال به‌تنهایی «مرتبه‌ی کمینه‌ی هر سه سری» به‌طور یکتا تعیین نمی‌شود و می‌توان بودجه‌ی خطا را به شکل‌های مختلف میان سه تقریب تقسیم کرد. یک انتخاب کافی آن است که

$$5.092 \Delta a + 0.636 \Delta b + 6.079 \Delta c  \leq 10^{-5}$$

برای مثال حالت زیر را انتخاب می‌کنیم.
$$\Delta a  = 10^{-7}$$
$$\Delta b = 10^{-6}$$
$$\Delta c = 10^{-6}$$

این انتخاب واقعاً خطای کل را تضمین می‌کند. با قضیه‌ی مقدار میانگین چندمتغیره و با توجه به
\(c\geq\pi/6\)، در تمام پاره‌خط میان مقدارهای دقیق و تقریبی داریم
\[
 |\widetilde c|\geq \frac{\pi}{6}-10^{-6},
 \qquad |\widetilde a|\leq1+10^{-7},
 \qquad |\widetilde b|\leq1+10^{-6}.
\]
پس
\[
 |\Delta k|
 \leq
 \frac{8(1+10^{-7})}{3(\pi/6-10^{-6})}10^{-7}
 +\frac{1}{3(\pi/6-10^{-6})}10^{-6}
 +\frac{4(1+10^{-7})^2+(1+10^{-6})}
 {3(\pi/6-10^{-6})^2}10^{-6}
 <7.23\times10^{-6}<10^{-5}.
\]

و با استفاده از حد بالای خطای سری هر کدام تعداد جملات مورد نیاز را حساب می‌کنیم:

برای $\sin(.)$:
$$|\Delta \sin(x)| \leq \abs{\frac{x^{2n+1}}{(2n+1)!}} \leq 10^{-7}$$
$$n=8 \Rightarrow \frac{(5\pi/6)^{17}}{17!}\approx 3.58425\times10^{-8}<10^{-7}.$$
برای \(n=7\) این کران حدود
\(1.42243\times10^{-6}\)
است؛ پس \(n=8\) کمترین مقدار کافی برای بودجه‌ی خطای انتخاب‌شده در این شماره‌گذاری است و چندجمله‌ای سینوس تا درجه‌ی \(15\) نگه داشته می‌شود.

برای $\cos(.)$: 
$$|\Delta \cos(x)| \leq \abs{\frac{x^{2n}}{(2n)!}} \leq 10^{-6}$$
$$n=8 \Rightarrow \frac{(5\pi/6)^{16}}{16!}\approx 2.32744\times10^{-7}<10^{-6}.$$
برای \(n=7\) این کران حدود
\(8.14990\times10^{-6}\)
است؛ پس در این‌جا نیز \(n=8\) کمترین مقدار کافی برای بودجه‌ی خطای انتخاب‌شده است و چندجمله‌ای کسینوس تا درجه‌ی \(14\) نگه داشته می‌شود.

برای $\tan^{-1}(.)$:
$$|\Delta \tan^{-1}(\frac{2x}{\pi \sqrt{3}})| \leq \abs{\frac{(\frac{5}{3\sqrt{3}})^{2n+3}}{(2n+3)}} \leq 10^{-6}$$
$$\frac{\left(\frac{5}{3\sqrt3}\right)^{2n+3}}{2n+3} \leq 10^{-6}$$
برای \(n=108\) کران برابر
\(9.99206\times10^{-7}\)
است، در حالی که برای \(n=107\) برابر
\(1.08909\times10^{-6}\)
می‌شود. بنابراین کمترین مقدار کافی در این شماره‌گذاری
\(n=108\)
است و جمله‌های سری تا توان \(217\) نگه داشته می‌شوند.

به دلیل عدم وجود فاکتوریل در مخرج جملات این سری، سری بسیار کند همگرا می‌شود. این کندی در تعداد عبارات مورد نیاز برای به دست آوردن دقت مورد نیاز کاملاً مشهود است.
